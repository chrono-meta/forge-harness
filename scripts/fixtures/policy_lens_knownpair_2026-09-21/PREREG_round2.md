## v1 대비 변경 — 다섯, 전부 결과 전에 이유가 적혀 있던 것

1. **읽음 증거 조건을 뺀다.** v1 의 «고유 토큰(레포명)이 응답에 나타난다» 는 4줄 계약과 양립
   불가였다(VOID ②, 24 중 23 INVALID). 🟥 **대체 필터를 넣지 않는다.** VOID 는 S2(`QUOTE` 가
   받은 자료에 실재하나)를 «같은 것을 재는 더 강한 조건» 으로 제안했지만, 그것을 **유효성 필터**로
   쓰면 PHANTOM 런이 결론에서 빠진다 — 그건 F3 이 재려는 바로 그 실패를 삭제해 그라운딩 비율을
   공짜로 올리는 것이다. 그래서 S2 는 **측정으로만** 남고(F3 에 들어간다), 필터가 되지 않는다.
   ⇒ 채점 키의 `unique_token` = `NONE` (채점기가 게이트를 끈다 — 레인 P7).
   방향 확인: 자료를 안 읽은 팔은 NOQUOTE/PHANTOM 이 되어 **F3 쪽으로**, 무작위 RISK 는 **F1·F2
   쪽으로** 떨어진다. 이 변경은 렌즈에 유리한 쪽으로 접히지 않는다.
2. **CTRL 은 레포명을 가진 PR 본문을 그대로 받는다.** v1 의 «익명화» 는 v1 의 토큰 조건과 모순이라
   1차 러너가 이미 이렇게 돌렸다(`run_arms.sh` 머리 주석). 이제 그것을 봉인 본문으로 올린다.
   방향: 이름을 가진 CTRL 이 더 강한 컨트롤이라 ARM–CTRL 분리를 **어렵게** 만든다.
3. **정답키 = 지배 문장 전수.** v1 키는 PR 당 문장 둘로 잘려 있었다(VOID 2차 ②). 2차 키의
   규칙을 **주석이 돌아오기 전에** 고정한다:
   - 독립 주석자 1명(이 세션과 분리된 서브에이전트, 입력 = 정책 2 + PR 4 **사본뿐**, 1차 런·결과·
     키·봉인문 비공개)이 각 PR 에 대해 «그 문장 하나와 PR 만으로 거절/큰 변경 요구를 예측하기에
     충분한 정책 문장» 을 **CORE / BORDERLINE** 으로 전수 열거한다.
   - `KEY_round2.tsv` 의 지배 문장 = **(주석자 CORE ∪ BORDERLINE) ∪ (v1 `KEY.tsv` 의 문장)**.
     v1 문장은 1차 결과 전에 봉인됐으므로 합집합에 넣는 것은 결과 튜닝이 아니다.
     🟥 이 세션은 주석에 문장을 **더하지도 빼지도 않는다.** 유일한 가공 = 주석자가 줄바꿈을
     공백 하나로 이은 것을 그대로 쓰고, 정책 파일에 축자로 없는 문장은(채점기 정규화 후
     부분문자열 대조로) **버리고 그 사실을 RESULT 에 적는다.**
   - 🟥 **negative 픽스처(A2·B2)에 주석자가 CORE 를 하나라도 달면, 그 픽스처는 2차에서 돌리지
     않는다** — 정답키가 ACCEPT 인데 독립 독자가 거절 근거를 찾았다면 결함은 렌즈가 아니라
     픽스처 쪽이고, 그 위에서 잰 F2 는 의미가 없다. 그 경우 F2 는 **미발동**으로 적고 픽스처
     재설계를 따로 연다. BORDERLINE 만 달렸으면 그대로 돌리고 RESULT 에 명시한다.
4. **CTRL 인용 라벨을 채점기 어휘에 맞춘다.** CTRL 행에서 `grounding=PHANTOM` 은 v1 의
   `PHANTOM-CTRL` 과 같은 뜻이다(채점기는 `ontarget=NO-CORPUS` 를 함께 낸다). 새 라벨을 짓지
   않는다 — VOID 의 «B1» 을 여기서 닫는다.
5. **1차 런은 결론에 쓰지 않는다.** 2차는 새로 24 런을 돌린다. 1차 런을 새 키로 재채점하는 것은
   키를 본 뒤의 채점이 되므로 **하지 않는다.**

## 계기 생존 조건 — v1 에서 토큰 조건 하나만 빠진다

- 출력 바이트 > 0 이고 `RISK:` 첫 낱말이 HIGH|MEDIUM|LOW. 계약 미준수를 LOW 로 접지 않는다.
- 필드 중복(`RISK:`/`QUOTE:` 두 번)은 INVALID.
- 프롬프트에 팔 배정을 역추론할 문자열이 없다.
- `ARM_BLIND_PATHS` 가 `scripts/fixtures` 를 클론에서 제거한다 — 런 로그의 `BLIND-STRIP FAILED`
  0 건으로 확인.
- 🟥 **INVALID 가 한 칸(팔×픽스처)에서 2 rep 이상이면 그 칸은 PARTIAL** 이다(그 칸의 유효 rep 이
  바 3 에 못 미친다) — v1 의 PARTIAL 규칙이 그대로 적용된다.

## 🟥 반증 조건 — v1 에서 글자 그대로 옮긴다

- **F1 바닥**: ARM 에서 known-positive 2건 중 **어느 하나라도** 3 rep 중 2 rep 이상 flagged 가
  안 되면 → `0/9` 는 **렌즈의 성질로 확정**된다 → **이 렌즈는 짓지 않는다.** (주 채점 기준)
- **F2 판별**: ARM 의 (positive flagged 비율 − negative flagged 비율) **≤ 0** 이면 변별력 없음
  → **짓지 않는다.** 🟥 전부 flagged 는 전부 미flagged 와 **같은 실패**다.
- **F3 정책 읽기**: ARM 의 `GROUNDED` 비율이 2/3 미만이거나, GROUNDED 중 `ONTARGET` 이 2/3 미만
  이면 → 재정의한 «정책 읽기» 축도 서지 않는다(인용이 아니라 생성이다) → **그 축 주장을 버린다.**

(주 채점 = `HIGH` 만 flagged · 부 채점 = `HIGH`∪`MEDIUM` — 둘 다 싣는다. F1·F2 는 주 채점으로 판정.)
F3 의 분모: GROUNDED 비율 = ARM positive 유효 런 중 `QUOTE` ≠ NONE 인 런 기준.
ONTARGET 비율 = 그중 GROUNDED 인 런 기준. NOQUOTE 는 GROUNDED 분모에서 **실패로 센다**
(인용하지 않은 것은 정책을 읽었다는 증거가 아니다) — 이것은 v1 이 명시하지 않았던 분모를
**결과 전에** 여기서 고정하는 것이고, 렌즈에 불리한 쪽이다.

## 결과 해석표 — v1 그대로

| ARM positive | CTRL positive | 읽기 |
|---|---|---|
| flagged | 미flagged | 정책 코퍼스가 유효 성분 — 재설계 다리 1(지운 변수 복원) 지지 |
| flagged | flagged | 본문만으로 자명한 픽스처 — Q1 은 답했으나 **코퍼스 기여는 이 픽스처로 미측정**. 「코퍼스 무용」으로 읽지 않는다 |
| 미flagged | 무엇이든 | **F1 발동** — 렌즈 폐기 |

축 B 에서 ARM=CTRL 이면 «코퍼스가 유일한 출처인 자리에서조차 기여가 없다» — F3 보다 강한 부정 신호.

## 이 측정이 주장하지 «않는» 것 — v1 그대로 + 하나

- 실제 메인테이너 예측력을 재지 않는다 · 통과해도 `standpoint: tier3` 가 아니다 · reps=3 은
  최소치 · 가공 픽스처는 «정책이 명시된 세계» 만 가정한다 (v1 §주장하지 않는 것).
- 🟥 **추가**: 저자가 1차 분포를 알고 있으므로 이 측정은 **완전한 사전등록이 아니다.** 보존된
  것은 «반증 조건이 결과 전에 고정됐다» 이고, 잃은 것은 «설계 선택이 결과를 모른 채 내려졌다» 이다.
  위 변경 다섯이 전부 VOID 문서에 결과 전 이유가 적힌 것으로 한정된 이유가 그것이다.
