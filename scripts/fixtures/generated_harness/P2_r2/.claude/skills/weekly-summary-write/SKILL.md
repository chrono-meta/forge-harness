# 주간 요약 작성

## 문서 구조
```
# 주간 회의 요약 (YYYY-MM-DD ~ YYYY-MM-DD)
## 한눈에 보기       ← 3~5줄. 이번 주 핵심 결정과 가장 급한 액션
## 결정 사항          ← 항목별 한 줄 + 배경 한 줄
## 액션 아이템        ← 표: 할 일 | 담당자 | 기한 | 출처
## 안건별 진행 상황   ← 안건마다 2~4줄. 지난 회의 대비 변화 포함
## 미결 사항·확인 필요
```

## 규칙
- 독자는 회의에 없던 사람이라고 가정한다. 약어와 내부 지칭은 풀어 쓴다.
- 정리본의 사실만 쓴다. 담당자·기한이 없으면 "미지정"으로 둔다.
- 기간은 처리한 회의록의 가장 이른 날짜와 늦은 날짜로 채운다.
- 한 문서는 A4 두 장 안팎으로 유지한다. 길어지면 안건별 진행 상황을 줄인다. 핵심 섹션은 줄이지 않는다.

## 검토 의견 반영
