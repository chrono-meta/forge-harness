# 회의록 정리

## 절차
1. 지정된 파일을 모두 읽는다. 날짜는 파일명이나 본문 머리말에서 찾고, 없으면 `[날짜 미상]`으로 둔다.
2. 회의별로 다음 네 항목을 뽑는다.
   - **안건/논의**: 무엇을 논의했는지 한두 줄
   - **결정 사항**: 합의로 확정된 것만. 의견 수준은 논의에 둔다
   - **액션 아이템**: `할 일 / 담당자 / 기한` 형식
   - **미결 사항**: 다음 회의로 넘어간 질문
3. 같은 안건이 여러 회의에 걸치면 시간순으로 묶고 변화(결정 번복 등)를 표시한다.
4. 각 항목 끝에 `(출처: 파일명)`을 붙인다.

## 이유
- 결정과 의견을 섞으면 요약이 사실을 과장한다. 그래서 확정 여부를 기준으로 가른다.
- 출처는 나중에 검토자가 원본과 대조하는 유일한 단서다.

## 출력 형식
`_workspace/01_organizer_notes.md`: 맨 위에 처리한 파일 목록과 누락 파일, 그다음 회의별 정리, 마지막에 안건별 묶음.
