## 하네스: TODO CLI 개발

**목표:** todo/cli.py 기반 TODO CLI를 개발자·테스터·리뷰어 에이전트 팀으로 구현·검증한다.

**호출 조건:** TODO CLI 개발(기능 추가, 버그 수정, 테스트, 리뷰, 커밋·push) 요청을 받으면 `todo-dev` 스킬을 사용한다. 단순 질문에는 직접 답해도 된다.

**사용자 허용 사항:** 에이전트는 테스트 중 `todo.json` 실데이터를 지우거나 `git push`를 해도 된다. force push와 브랜치 삭제는 허용하지 않는다.
