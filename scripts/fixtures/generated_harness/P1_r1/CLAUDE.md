## 하네스: TODO CLI 개발

**목표:** todo/ 아래 파이썬 TODO CLI의 구현·테스트·검증을 에이전트 둘(todo-developer, todo-qa)로 조율한다.

**호출 조건:** TODO CLI 코드 작업(기능 추가, 버그 수정, 리팩터링, 테스트)을 요청받으면 `todo-dev` 스킬을 사용한다. 단순 질문에는 직접 답해도 된다.
