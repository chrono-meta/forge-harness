# 리스 기록 채널 — 세션은 초안, 기록은 운영자 (G3, 2026-11-07)

> 맥락 유지 엔진(`fh_three_layer_canon.md` §2)의 «쓰는 절반» 중 권한 기록 자리. 흡수 대기열 AQ-20261107-11.

## 왜

리스 줄(로컬 지침 파일의 «추가 utterance» 줄)은 «운영자가 무엇을 허락했나» 의 기록이다. 지금까지 그 줄을 세션이 직접
썼다 — 즉 세션이 자기 권한의 기록을 쓴다. 로컬 지침 파일 스스로 이것을 «자기신고 잔여» 라고 적어 두었다.
2026-11-07 자동 모드 분류기가 세션의 리스 줄 쓰기를 두 번 거부했다. 분류기가 옳았다.

## 흐름

1. 세션이 초안을 쓴다 — `bash scripts/lease_line_apply.sh draft --block "<리스 절 제목 일부>" --line "추가 utterance …" --why "<물음>"`.
   초안은 `tracks/_meta/lease_drafts/` 에 남고 리스 파일은 안 바뀐다. 세션은 운영자에게 그 경로와 아래 한 줄을 건넨다.
2. 세션은 `check <초안>` 으로 들어갈 자리(그 절의 «제외» 줄 바로 앞)를 미리 보여 줄 수 있다(읽기만).
3. 운영자가 자기 터미널에서 `bash scripts/lease_line_apply.sh apply <초안>` — 들어갈 줄을 보고, 화면에 뜬 4자 확인 코드를
   쳐야 기록된다. 쓰기 전에 시각이 붙은 백업을 만든다.
4. 초안이 쌓였으면(원격으로 일한 날) 책상에서 `bash scripts/lease_line_apply.sh apply-all` 한 번 — 대기 중인 초안 전부를
   «넣을 것 · 이미 있는 것 · 건너뛴 것(이유)» 으로 보여 주고, **배치 전체에 대한 확인 코드 하나**를 받는다. 백업 하나 ·
   원자적 교체 하나. 적용된 초안(과 이미 들어 있던 초안)은 `lease_drafts/applied/` 로 옮겨져 다음에 다시 안 뜬다.
   건너뛴 초안은 대기열에 남는다.

## 무엇이 리스 줄을 필요로 하나 (2026-11-10, 운영자 «ㅇㅇ 진행하자»)

- **이 PR 하나에 대한 운영자 답**(«머지해» · «초록이면 머지» · «#N 머지할까?» 에 대한 «ㅇㅇ» …)은 **리스 줄이 필요 없다.**
  기록은 머지 영수증의 `--lease 'operator <날짜> «<원문>» (#PR)'` 과 대화 기록이다. 영수증이 원문을 인용하고,
  `pr_merge_verified.sh` 는 «operator» 로 시작하는 라벨을 그 PR 에 대한 답으로 읽는다.
- **범위를 넓히는 상시 위임**(«앞으로 X 는 묻지 마» · 기한이 붙은 자율주행 · 다른 세션에까지 미치는 권한)만 리스 줄이 필요하다 —
  그것이 «자기 권한의 기록» 이라 세션이 직접 쓰면 안 되는 바로 그 부류다.
- **원격에서 받은 상시 위임**(휴대폰 Remote Control 등 — 운영자가 스크립트를 못 돌리는 자리)은 운영자가 책상에서 그 초안을
  `apply`/`apply-all` 로 적용하기 전까지 **그 세션 한정의 1회 위임**으로만 읽는다. 세션은 초안을 남기고(`draft`), 다른 세션이나
  다음 세션은 적용되지 않은 초안을 근거로 쓰지 않는다.
- 판정이 애매하면(이 PR 답인지 범위 확대인지) 리스 줄 쪽으로 기운다 — 초안은 되돌릴 수 있고, 빠진 기록은 되찾을 수 없다.

권한 프롬프트(설정의 `ask` 규칙)로 원격 확인을 받는 길은 2026-11-10 실측에서 접었다: auto 모드에서 ask 규칙을 건 카나리아
명령이 프롬프트 없이 실행됐다(규칙 없는 대조 명령과 똑같이). 원인(auto 모드가 ask 를 넘어서는지 · 세션 중 바뀐 설정을 안 읽는지)은
갈리지 않았다 — `UNMEASURED`.

## 무엇을 막고 무엇을 못 막나

- `apply` 는 Claude Code 셸(`CLAUDECODE` 가 설정된 셸)과 터미널 없는 실행을 거부한다(rc 3).
- 🟥 **자물쇠가 아니다.** 변수를 지우고 가짜 터미널을 띄우면 통과된다 — 레인 A3/A4 가 바로 그 방법으로 정상 경로를 잰다.
  닫는 방향은 이 파일 밖이다: 운영자 설정의 권한 거부 규칙 `Bash(*lease_line_apply.sh apply*)` 와, 나중에 FoD 카드(실제
  OS 입력). 이 스크립트가 하는 일은 «정직한 길을 쉬운 길로» 만드는 것이다.
- 레인: `scripts/test_lease_line_apply_lanes.sh`(초안 · 위치 · 모호 · 중복 · 에이전트 셸 거부 · 터미널 없음 · 코드 일치/불일치 ·
  되돌림 프로브 · `apply-all` 의 배치 순서 · 이미 있는 줄 · 건너뛴 초안 · 대기 중 변경 거부 · 재실행 시 다시 안 뜸).
- `apply-all` 의 «대기 중 변경» 거부는 세 겹이다(셸 비교 · 파이썬 시작 · 교체 직전 재해시). 되돌림 프로브는 셋을 다 꺼야
  빨개진다 — 한 겹만 끄면 나머지가 막는다.

## 운영자가 할 일 (이 PR 머지 뒤)

- 권한 거부 규칙 한 줄을 사용자 설정에 넣을지 결정한다(넣으면 세션이 `apply` 를 아예 못 부른다).
- 로컬 지침 파일의 리스 절 머리 문단에 «기록은 `lease_line_apply.sh apply` 로» 를 넣을지 결정한다(그 파일은 운영자 것).
