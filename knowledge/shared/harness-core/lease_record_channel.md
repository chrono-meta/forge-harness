# 리스 기록 채널 — 세션은 초안, 기록은 운영자 (G3, 2026-11-07)

> 맥락 유지 엔진(`fh_three_layer_canon.md` §2)의 «쓰는 절반» 중 권한 기록 자리. 흡수 대기열 AQ-20261107-11.
> 브리프 `tracks/_meta/brief_governor_role_items_2026-11-07.md` §G3.

## 왜

리스 줄(로컬 지침 파일의 «추가 utterance» 줄)은 «운영자가 무엇을 허락했나» 의 기록이다. 지금까지 그 줄을 세션이 직접
썼다 — 즉 세션이 자기 권한의 기록을 쓴다. 로컬 지침 파일 스스로 이것을 «자기신고 잔여» 라고 적어 두었다.
2026-11-07 자동 모드 분류기가 세션의 리스 줄 쓰기를 두 번 거부했다. 분류기가 옳았다.

## 흐름

1. 세션이 초안을 쓴다 — `bash scripts/lease_line_apply.sh draft --block "<리스 절 제목 일부>" --line "추가 utterance …" --why "<물음>"`.
   초안은 `tracks/_meta/lease_drafts/` 에 남고 리스 파일은 안 바뀐다. 세션은 운영자에게 그 경로와 아래 한 줄을 건넨다.
2. 세션은 `check <초안>` 으로 들어갈 자리(그 절의 «제외» 줄 바로 앞)를 미리 보여 줄 수 있다(읽기만).
3. 운영자가 자기 터미널에서 `bash scripts/lease_line_apply.sh apply <초안>` — 들어갈 줄을 보고, 화면에 뜬 4자 확인 코드를
   쳐야 기록된다. 쓰기 전에 시각이 붙은 백업을 만든다.

## 무엇을 막고 무엇을 못 막나

- `apply` 는 Claude Code 셸(`CLAUDECODE` 가 설정된 셸)과 터미널 없는 실행을 거부한다(rc 3).
- 🟥 **자물쇠가 아니다.** 변수를 지우고 가짜 터미널을 띄우면 통과된다 — 레인 A3/A4 가 바로 그 방법으로 정상 경로를 잰다.
  닫는 방향은 이 파일 밖이다: 운영자 설정의 권한 거부 규칙 `Bash(*lease_line_apply.sh apply*)` 와, 나중에 FoD 카드(실제
  OS 입력). 이 스크립트가 하는 일은 «정직한 길을 쉬운 길로» 만드는 것이다.
- 레인: `scripts/test_lease_line_apply_lanes.sh`(초안 · 위치 · 모호 · 중복 · 에이전트 셸 거부 · 터미널 없음 · 코드 일치/불일치 ·
  되돌림 프로브).

## 운영자가 할 일 (이 PR 머지 뒤)

- 권한 거부 규칙 한 줄을 사용자 설정에 넣을지 결정한다(넣으면 세션이 `apply` 를 아예 못 부른다).
- 로컬 지침 파일의 리스 절 머리 문단에 «기록은 `lease_line_apply.sh apply` 로» 를 넣을지 결정한다(그 파일은 운영자 것).
