# 착지 후 압축 — 거버너가 관할 세션의 압축 시점을 앞당긴다 (G2′, 2026-11-07)

> 맥락 유지 엔진(`fh_three_layer_canon.md` §2)의 «시점» 보강.
> 출처: 운영자 2026-11-07 «거버너가 세션압축에 준비하라고 하고 난후에, 그쪽이 정리후 지금 바로 압축할지를
> 질문으로 띄우면 내가 확인할수있겠네».

## 왜

자동 압축은 일이 어디까지 왔는지 모르고 터진다. 2026-11-07 하위 세션 하나는 착지 전에 약 96% 에서
자동 압축됐다(→ 21%). 거버너가 97% 를 읽고 «착지 후 압축» 메시지를 보냈을 때 그 세션은 일하는 중이라 메시지가
큐에 걸렸고, 그 사이 자동 압축이 먼저 왔다. 표시값 `autoCompactsAtPercent: 97` 과 실제 발화(~96%)도 달랐다.

## 흐름

1. **읽는 때** — 하위 세션의 턴 끝 알림이 올 때마다 거버너가 `mcp__ccd_session_mgmt__get_usage {session_id}` 를 한 번
   읽는다. 폴링하지 않는다(알림이 곧 시점이다). idle·archived 세션은 `context.status` 가 `ok` 가 아니다 — 그건
   «여유 있음» 이 아니라 «못 읽음» 이다.
2. **판정** — 결과 JSON 을 파일로 두고 `python3 scripts/governor_landing_check.py --usage-json <파일>`.
   `0 OK` · `1 LAND` · `3 LATE` · `2 못 읽음`.
3. **LAND** — 그 세션에 보낸다: «지금 단위 마무리 · 인계 메모를 파일에 착지 · 경로 보고 · 그 뒤 운영자에게
   «지금 압축할까?» 질문». 질문은 그 세션의 wrap_up 질문 상자로 띄운다.
4. **압축은 운영자가 한다** — `/compact` 는 사람 명령이다. 거버너도 하위 세션도 압축을 직접 걸지 않는다.
   비우기(clear)는 매번 운영자 승인.
5. **LATE** — 자동 압축이 곧이거나 이미 지났다. 인계 메모 착지만 먼저 요청하고, 압축 뒤 첫 턴에 그 메모를 읽혔는지
   확인한다.

🟥 **압축 봉인 개수로 세지 않는다.** 봉인 파일 이름(`tracks/_meta/compaction/seal_<id>*`)은 CLI 전사본 id 이고
앱 세션 id(`local_…`)와 다르다 — 하위 세션은 0 으로 보여 «압축 없음» 과 구분이 안 된다. 그래서 G2(봉인 수 N 이상
권고)는 이 절차로 대체한다.

## 문턱

`문턱 = 실제 발화점 − 턴 증가량 × (1 + 큐 지연 턴)`

| 값 | 기본 | 근거 | 상태 |
|---|---|---|---|
| 실제 발화점 | min(표시값, 96) | 2026-11-07 관측 1회(표시 97 · 발화 ~96) | n=1 |
| 턴 증가량 | 3 %p | 추정 | **UNCALIBRATED** |
| 큐 지연 | 1 턴 | 2026-11-07 메시지가 진행 중 턴 뒤에 걸림 | n=1 |

⇒ 기본 문턱 90%. 근거는 위 세 칸이고, 그중 둘은 아직 측정 전이다.

## 문턱 실측 계획 (미실행)

- **턴 증가량**: 다음 주 관할 세션들의 턴 끝마다 `get_usage` 퍼센트를 한 줄씩 남긴다(세션 id · 시각 · 퍼센트).
  연속 두 값의 차의 분포에서 상위 10% 값을 «턴 증가량» 으로 쓴다(평균을 쓰면 큰 턴에서 늦는다).
- **실제 발화점**: 퍼센트가 큰 폭으로 떨어진 직전 값을 모은다(압축 표지). 표시값과 다르면 그 차를 기록한다.
- **큐 지연**: 거버너가 메시지를 보낸 시각과 그 세션이 처리한 턴 수를 같이 적는다.
- **효과**(가설, 미측정): «착지 후 압축» 이 자동 압축보다 앞 결정을 더 보존하는지 — 격리 sim(압축 뒤 앞 결정 질문 →
  낡은 답 비율)을 두 팔로 비교한다. `scripts/sim_isolated_run.sh` 를 쓴다(실 체크아웃에서 sim 금지).
- 갱신은 주간 감사에서 — 값이 바뀌면 이 표와 스크립트 기본값을 같은 PR 로 바꾼다.

## 이름 붙인 잔여

- 이 절차는 거버너가 **알림을 받을 때만** 돈다. 거버너가 없는 단독 세션은 자동 압축 그대로다.
- 판정기는 퍼센트만 본다. 일이 «단위 경계» 에 있는지는 하위 세션의 판단이다.
- 레인: `scripts/test_governor_landing_check_lanes.sh`(문턱 경계 · 표시값 불신 · 못 읽음 ≠ OK · 되돌림 프로브).
